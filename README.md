Huddle Landing Page with Styled Components

This is my solution to the Huddle landing page with single introductory section challenge
 from Frontend Mentor.

🚀 Overview

This project recreates the Huddle landing page using React and Styled Components.
I built it as part of my learning journey to get hands-on experience with Styled Components, which I hadn’t used before.

I followed the designs provided by Frontend Mentor and implemented a responsive layout that adapts to desktop and mobile screens.

🎯 The Challenge

Users should be able to:

View the landing page optimized for desktop and mobile.

See hover states for interactive elements.

Enjoy a clean, responsive layout that closely matches the provided designs.

🛠️ Built With

React
 – for building the UI

Styled Components
 – for component-based styling

Semantic HTML5 & CSS3

Flexbox for layout

Mobile-first workflow

💡 What I Learned
Using Styled Components to create reusable, theme-aware UI elements.
Handling responsive design with Styled Components’ media queries.

This was my first project using Styled Components, and it helped me understand how to keep styles scoped, reusable, and maintainable.
